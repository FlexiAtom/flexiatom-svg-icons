# FlexiAtom SVG 图标

这是 FlexiAtom 的 SVG 图标合集，也是一个「提示词 + 产物」仓库：`prompts/` 保存生成图标所用的提示词，`outputs/` 保存对应的 SVG 产物。

## 目录结构

- `prompts/` — 图标提示词
- `outputs/` — 提示词生成的 SVG 图标

## 图标列表

| 图标 | 提示词 |
| --- | --- |
| `outputs/floppy-disk.svg` — 软盘图标 | `prompts/floppy-disk_svg.md` |
| `outputs/paper-and-pen.svg` — 纸笔图标 | `prompts/paper-and-pen_svg.md` |
